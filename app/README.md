# How Predictable You Are (Flutter Workspace)

This directory contains the cross-platform Flutter application for **How Predictable You Are**, an interactive casual strategy and probability game.

For full project documentation, architectural overview, and roadmaps, please refer to the root [README.md](../README.md).

## Quickstart

```bash
flutter pub get
flutter test
flutter run
```

## Running Tests

```bash
flutter test
```
