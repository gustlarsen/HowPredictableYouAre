# How Predictable You Are

This Flutter project is a port of the Kodular app found in the extracted `.aia` archive. It reproduces the Rock Paper Scissors gameplay with a Markov-prediction strategy, AI hand selection, localization, dark mode, audio, and upgrade-style progression.

## Run locally

```bash
flutter pub get
flutter run
```

## Included behaviors

- Predictive AI based on historical player choices
- Markov transition matrix visualization
- Rock/Paper/Scissors gameplay with optional extended hands
- Score tracking, diamonds, and evaluation tiers
- English/German/Portuguese/Spanish localization
- Dark mode and themed game screen
- Separate sound-effects, background-music, and vibration settings
- Audio cues and asset-based animations
